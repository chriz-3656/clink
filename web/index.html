Architectural Operating Modes

Three specialized execution modes tailored for live annotation, pressure graphics, and system control.

Mode A: Absolute Desktop Annotation

Real-time transparent drawing canvas sitting directly over your live desktop. Uses X11 XFixes/XShape empty input regions so mouse clicks bleed 100% through to IDEs, browsers, and terminal windows.

Mode B: Relative Graphics Tablet

Transforms any phone or tablet into an external graphics tablet for Krita, GIMP, Blender, and Inkscape. Features subpixel float accumulation, hardware stylus pressure, and tablet controller docks.

Mode C: Studio Companion

Native single-binary Rust engine (<10MB RAM, sub-millisecond startup) with centered studio UI, real-time in-memory event activity logger, and QR camera optical pairing.

Direct zero-jitter cable link. Ideal for 120Hz high-precision stylus illustration.

Antenna-to-antenna wireless pairing in parks, lecture halls, or flights.

Universal GLIBC 2.28+ Symbol Compatibility

Standard Ubuntu 24.04 builds bind mathematical symbols like atan2f and acosf to GLIBC_2.43, causing dynamic linker errors on Debian 10/11/12 and Ubuntu 20.04/22.04.

Clink solves this by cross-compiling with cargo-zigbuild targeting x86_64-unknown-linux-gnu.2.28. All binary symbols are constrained to GLIBC 2.28 or lower, making Clink universally runnable across all mainstream Linux distros without containerization.

# Verify maximum GLIBC symbol requirement: readelf -V /usr/bin/clink | grep -E 'Name: GLIBC_' | sort -u # Result: GLIBC_2.2.5, GLIBC_2.3, GLIBC_2.14, GLIBC_2.17, GLIBC_2.28 (Maximum is 2.28)

Linux Firewall & Troubleshooting

# Allow incoming WebSocket traffic on port 8765: sudo ufw allow 8765/tcp # For Fedora / RHEL firewalld: sudo firewall-cmd --add-port=8765/tcp --permanent sudo firewall-cmd --reload
