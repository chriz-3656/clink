Technical Specifications

Performance metrics and architecture comparison between Clink and traditional screen-sharing tablets.

Subsystem Implementation Details Performance Target
Transport Protocol Binary WebSocket over TCP (RFC 6455) < 0.8 ms roundtrip latency
Overlay Compositor X11 Composite / Windows Layered Window with tiny-skia 2D rasterizer 60 FPS zero-tearing transparent render
Input Injection Linux XTest extension with subpixel accumulator / Windows SendInput API Smooth subpixel cursor tracking without jitter

Automated ADB Reverse Tunnel

When connected via USB, the desktop companion issues adb reverse tcp:8765 tcp:8765. Port 8765 is redirected over the hardware USB bus, bypassing local firewall or network restrictions.

Triple-Mode Multi-Interface Probing

The companion dynamically enumerates all network interfaces and identifies Portable Hotspots (192.168.43.x, 10.42.0.1, 192.168.137.1), generating valid QR pairing payloads for direct connections.

Configurable Auto-Fade Timers

Annotate on top of live meetings, IDEs, or presentation slides. Set auto-fade timers (3s, 5s, 10s) or keep persistent strokes. Background thread fades strokes with zero CPU impact.
